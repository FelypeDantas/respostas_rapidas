PAINEL DE RESPOSTAS RÁPIDAS - V1

Como usar:
1. Abra o arquivo index.html no navegador.
2. Clique em "Nova resposta" para cadastrar textos.
3. Organize por categorias.
4. Clique em "Copiar texto".
5. Se o texto tiver variáveis como {nome}, {data} ou {protocolo}, o sistema pedirá os valores.
6. Os dados ficam salvos no navegador usando localStorage.
7. Use "Exportar" para salvar um backup em JSON.

Observação:
Esta primeira versão é 100% local e não precisa de servidor, banco de dados ou instalação.
